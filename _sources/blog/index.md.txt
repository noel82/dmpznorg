Well, here we are!  

This is the first blog post on this website. Actually, this is not my first blog post on the internet, _at all_: I started my blogging career (kidding) in 2003 when, while working as network administrator for a local IT company, I started my own blog platform. 
  
 
At that time there was no Wordpress, so I decided to code my own CMS system as side project (it was in ASP 2.0 and VBScript): admin dashboard, comment sections and some tricks to avoid spam (some of those are still used today, in the modern era). Sadly I do not own the domain anymore but I still have the codebase.  
  
This website runs static files generated through a custom flow I coded, all built using [Sphinx](https://www.sphinx-doc.org/en/master/). So no fancy dashobards or plugins to update on a daily basis: just markdown files and a template. That's all.    
  
Anyway, I hope to write a lot more here: next step is to fill the project section and talk about something interesting in the next posts.
